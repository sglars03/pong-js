# JUEGO DE PONG

## Descripcion 

Juego de pong para dos personas en el mismo teclado. Desarrollado con HTML,CSS y JavaScript.

## Objetivo 

Mi objetivo es construir una version jugable con dos paletas (simulando a dos porteros), una pelota, marcador de puntos, pausa y reinicio.

## Controles previstos 

- Jugador izquierdo: W y S.
- Jugador derecho: flechas arriba y abajo.
- Entener: sacar.
- P: pausar o continuar 
- R: Reiniciar.
